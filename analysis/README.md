# Analysis code and numerical results

The Python scripts are intentionally stored beside their CSV, JSON, NPZ and
SVG outputs because each script resolves outputs relative to its own location.

Use the repository-level `run_core_experiments.ps1` rather than executing
scripts in arbitrary order. `paper/core_experiment_manifest.md` describes each
experiment and its main outputs.

All random experiments use fixed seeds. No local absolute path is required.
