# Third-party software and data

## QEDispInv

- Upstream repository: <https://github.com/pan3rock/QEDispInv>
- Tested commit: `ed1b5dd7`
- Repository-root license in the inspected copy: LGPL-3.0.
- Several inspected source headers state GPL-3.0.

Because the upstream licensing metadata is inconsistent, QEDispInv source,
compiled binaries and the portable MSYS2 environment are not redistributed
here. The repository includes only:

- our input model and configuration;
- the output used for comparison;
- our wrapper and comparison script;
- build notes and the tested upstream commit.

Users should obtain QEDispInv from its upstream repository and comply with the
license clarified by its authors.
